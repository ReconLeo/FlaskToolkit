# i18n 国际化同步

本页覆盖 FlaskToolkit 框架的 i18n 机制与同步工具。任何界面文案变更、新增模板中文 key、或插件多语言打包，都按本页处理。

## 语言包结构 `locales/`

- `en.json` —— **完整参考基准**（英文）。校验/创建其它语言包都以它为基准。
- `zh-CN.json` —— **源语言**：key 即中文原文，缺省回退返回原文，视为完整覆盖。
- 其它语言（如 `fr.json`）：以 en.json 为完整参考对照翻译进度。
- 元信息字段固定前缀 `__`（如 `__name__` 语言自称、`__contributors`），不参与翻译对照。

## 工具（互补，两套都要理解）

| 工具 | 作用 |
|------|------|
| `python tools/i18n_status.py` | 语言包侧：以 en.json 为基准查各语言翻译进度；`--check` 校验全部语言包 JSON 合法；`--create fr --name 法语` 基于 en.json 创建新语言包；`--json` 供脚本/CI |
| `python tools/scan_missing_i18n.py` | 框架侧：扫描 `templates/` 下调用 `t()/window.T()/T()` 的中文文案，若未收录到 `locales/en.json`（key 即中文原文），列出缺失项及来源文件 |

- `i18n_status.py` 的内置语言 en（参考基准）与 zh-CN（源语言）**不可创建/修改**；其它语言可自行创建。
- 新增其它语言包可通过 `i18n_status.py --create`，鼓励 GitHub 翻译贡献（contributors 元信息）。

## 框架取词方式

- 后端：`self.t("中文key")`（BasePlugin / 框架模块的 i18n 取词）。
- 模板/前端：`t("中文key")`、`window.T("...")`、`T("...")`（templates/ 下调用，key 即中文原文）。

## 文案变更流程（改文案/加文案后必走）

1. 在 `templates/`（或代码）中加入/修改 `t()/T()` 中文文案。
2. 把新中文 key 补进 `locales/en.json`（key 即中文原文，value 为对应英文）。
3. 跑 `python tools/scan_missing_i18n.py`，确认无未收录的模板中文 key。
4. 如需为其它语言补翻译，跑 `python tools/i18n_status.py` 查看进度并按需补。
5. 若新增/修改了贡献者或语言包，用 `i18n_status.py --check` 校验 JSON 合法。
6. 若涉及 README/开发规范的 i18n 数字（翻译状态/语言包数量），按 [dev-conventions.md](dev-conventions.md) 文档双同步。

## 插件语言包（示例插件多语言）

- 插件可带 `locales/` 语言包随插件打包，框架安装时合并插件词条。
- 插件取词用 `self.t()`；缺失词条回退中文。
- 升级带语言包插件时，确认 `extract_plugin_pack` 分支会处理 `locales/`（历史缺陷：早期版本落入 else 被忽略，导致插件词条合并不到、`self.t()` 回退中文）。
- 打包命令与字段一致性见 [example-plugins.md](example-plugins.md)。

## 测试断言

- `tests/test_i18n.py` 有翻译覆盖断言；新增模板 key 后确认不破坏该断言。
- i18n 相关改动需跑全量回归，见 [testing.md](testing.md)。
